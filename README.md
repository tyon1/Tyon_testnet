# 🧪 Tyon Testnet Sandbox

Welcome to the **Tyon Testnet** — a modular, auditable sandbox for staging FRE document serialization, metadata stamping, and trust-first protocol flows.

> “Break it. Rebuild it. Trust it.” — Byte

---

## 🚀 Purpose

This testnet mirrors our mainnet architecture, enabling safe experimentation and validation of:

- 🔐 **FRE metadata stamping** with `tyonId`, `txId`, and Hashscan verification
- 📄 **Document serialization** with audit trails
- 🧪 **Environment switching** via `.env` files
- 🧰 **Modular backend structure** for scalable deployment
